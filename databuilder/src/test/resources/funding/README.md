# Appropriations test fixtures

`AppropriationsBillTest` uses official bill text and checks specific published amounts. It runs offline.

The compressed text fixtures for New Mexico HB 2 and Texas SB 1 are complete PDF text extractions using the builder's `PDFToText`. They cover the [introduced New Mexico bill](https://www.nmlegis.gov/Sessions/26%20Regular/bills/house/HB0002.pdf), [final New Mexico bill](https://www.nmlegis.gov/Sessions/26%20Regular/final/HB0002.pdf), and [enrolled Texas bill](https://capitol.texas.gov/tlodocs/89R/billtext/pdf/SB00001F.pdf).

- Congress uses the full GovInfo XML for each version. For a filename such as `s2256rs.xml.gz`, the source is [BILLS-119s2256rs](https://www.govinfo.gov/content/pkg/BILLS-119s2256rs/xml/BILLS-119s2256rs.xml). The comparison uses the explicit levels in [H.R. 1968, enrolled](https://www.govinfo.gov/content/pkg/BILLS-119hr1968enr/xml/BILLS-119hr1968enr.xml), including its FY 2026 advance appropriations.
- Arizona uses agency table excerpts from the legislature's [HB 2897](https://www.azleg.gov/legtext/56leg/2r/laws/0209.htm), [SB 1735](https://www.azleg.gov/legtext/57leg/1r/laws/0233.htm), [HB 2947](https://www.azleg.gov/legtext/57leg/1r/bills/hb2947p.htm), [HB 4138](https://www.azleg.gov/legtext/57leg/2r/bills/hb4138p.htm), and [SB 1847](https://www.azleg.gov/legtext/57leg/2r/laws/0126.htm).
- Colorado uses the Agriculture totals from [SB 23-214](https://leg.colorado.gov/laws/session-laws/SB23-214/474/download), [HB 24-1430](https://leg.colorado.gov/laws/session-laws/HB24-1430/519/download), [SB 25-206](https://leg.colorado.gov/laws/session-laws/SB25-206/476/download), and [HB 26-1410](https://leg.colorado.gov/laws/session-laws/HB26-1410/436/download).
- Georgia uses the State Funds totals in legislative budget text for [HB 916](https://www.legis.ga.gov/api/document/docs/default-source/house-budget-and-research-office-document-library/2025-fiscal-year/fy_2025_bill_house_version_%28hb_916%29.pdf), [HB 68](https://www.legis.ga.gov/api/document/docs/default-source/house-budget-and-research-office-document-library/2026-fiscal-year/fy_2026_bill_house_version_%28hb_68%29.pdf), [HB 973](https://www.legis.ga.gov/api/document/docs/default-source/house-budget-and-research-office-document-library/2026-fiscal-year/amended_fy_2026_bill_house_%28hb_973%29.pdf), and [HB 974](https://www.legis.ga.gov/api/document/docs/default-source/house-budget-and-research-office-document-library/2027-fiscal-year/fy_2027_bill_conf_cmte_%28hb_974%29.pdf). The fixtures identify the publication versions so they can be checked against those exact versions.
- New Mexico uses totals from Section 4 of the [2023](https://www.nmlegis.gov/Sessions/23%20Regular/final/HB0002.pdf), [2024](https://www.nmlegis.gov/Sessions/24%20Regular/final/HB0002.pdf), [2025](https://www.nmlegis.gov/Sessions/25%20Regular/final/HB0002.pdf), and [2026](https://www.nmlegis.gov/Sessions/26%20Regular/final/HB0002.pdf) final versions of HB 2.
- Texas uses the two fiscal-year columns in the all-funds recap of [86R HB 1](https://capitol.texas.gov/tlodocs/86R/billtext/pdf/HB00001F.pdf), [87R SB 1](https://capitol.texas.gov/tlodocs/87R/billtext/pdf/SB00001F.pdf), [88R HB 1](https://capitol.texas.gov/tlodocs/88R/billtext/pdf/HB00001F.pdf), and [89R SB 1](https://capitol.texas.gov/tlodocs/89R/billtext/pdf/SB00001F.pdf).
